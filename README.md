# 로또

## 기능 요구 사항
- 로또 번호의 숫자 범위는 1~45까지이다.
- 1개의 로또를 발행할 때 중복되지 않는 6개의 숫자를 뽑는다.
- 당첨 번호 추첨 시 중복되지 않는 숫자 6개와 보너스 번호 1개를 뽑는다.
- 당첨은 1등부터 5등까지 있다.
- 로또 구입 금액을 입력하면 구입 금액에 해당하는 만큼 로또를 발행해야 한다.
- 로또 1장의 가격은 1,000원이다.
- 사용자가 잘못된 값을 입력할 경우 `IllegalArgumentException`을 발생시키고, "[ERROR]"로 시작하는 에러 메시지를 출력 후 그 부분부터 입력을 다시 받는다.

## 입출력 요구 사항

### 입력
- 로또 구입 금액
- 당첨 번호 6개 (쉼표로 구분)
- 보너스 번호 1개

### 출력
- 구매한 로또 개수와 번호 목록
- 당첨 통계
- 총 수익률

### 실행 결과 예시
```
구입금액을 입력해 주세요.
8000

8개를 구매했습니다.
[8, 21, 23, 41, 42, 43] 
[3, 5, 11, 16, 32, 38] 
[7, 11, 16, 35, 36, 44] 
[1, 8, 11, 31, 41, 42] 
[13, 14, 16, 38, 42, 45] 
[7, 11, 30, 40, 42, 43] 
[2, 13, 22, 32, 38, 45] 
[1, 3, 5, 14, 22, 45]

당첨 번호를 입력해 주세요.
1,2,3,4,5,6

보너스 번호를 입력해 주세요.
7

당첨 통계
---
3개 일치 (5,000원) - 1개
4개 일치 (50,000원) - 0개
5개 일치 (1,500,000원) - 0개
5개 일치, 보너스 볼 일치 (30,000,000원) - 0개
6개 일치 (2,000,000,000원) - 0개
총 수익률은 62.5%입니다.
```

## 구현할 기능 목록

### 1. 입력 기능
- 구입 금액 입력
    - 1,000원 단위 검증
    - 양수 검증
    - 숫자 형식 검증
- 당첨 번호 입력
    - 쉼표 구분자로 파싱
    - 6개 숫자 검증
    - 1~45 범위 검증
    - 중복 검증
- 보너스 번호 입력
    - 1~45 범위 검증
    - 당첨 번호와 중복 검증

### 2. 로또 생성 기능
- 구입 금액으로 로또 개수 계산
    - 구입 금액 / 1,000원 = 로또 개수
- 로또 번호 자동 생성
    - 1~45 중 중복되지 않는 6개 숫자 추출
    - 오름차순 정렬하여 저장

### 3. 당첨 판정 기능
- 일치 번호 개수 계산
    - 구매한 로또와 당첨 번호 비교
- 보너스 번호 일치 확인
    - 5개 일치 시 보너스 번호 포함 여부 확인
- 등수 판정
    - 6개 일치: 1등 (2,000,000,000원)
    - 5개 일치 + 보너스: 2등 (30,000,000원)
    - 5개 일치: 3등 (1,500,000원)
    - 4개 일치: 4등 (50,000원)
    - 3개 일치: 5등 (5,000원)

### 4. 결과 계산 기능
- 당첨 통계 집계
    - 각 등수별 당첨 개수 계산
- 수익률 계산
    - (총 당첨 금액 / 구입 금액) × 100
    - 소수점 둘째 자리에서 반올림

### 5. 출력 기능
- 구매한 로또 출력
    - 구매 개수 출력
    - 각 로또 번호를 오름차순으로 출력
- 당첨 통계 출력
    - 각 등수별 당첨 개수와 상금 출력
- 수익률 출력
    - "총 수익률은 {rate}%입니다." 형식

### 6. 예외 처리 기능
- 구입 금액 예외
    - 1,000원 단위가 아닌 경우
    - 0 이하인 경우
    - 숫자가 아닌 경우
- 당첨 번호 예외
    - 6개가 아닌 경우
    - 1~45 범위를 벗어난 경우
    - 중복된 숫자가 있는 경우
    - 숫자가 아닌 문자가 포함된 경우
- 보너스 번호 예외
    - 1~45 범위를 벗어난 경우
    - 당첨 번호와 중복된 경우
    - 숫자가 아닌 경우
